# WEB102 Project 1 - *Community Board*

## Overview

This is a React-based Community Board application that displays a collection of events/resources in a clean, responsive card layout. Each card contains an image, title, description, date, and a link button that directs users to a relevant external resource.

The purpose of this project is to help a community discover useful learning resources and events in an organized and visually appealing way.

---

## 🎯 Features

### ✅ Required Features

- [x] The app has a cohesive, unique theme for events or resources relevant to a specific community  
  (Tech learning resources and developer events)

- [x] A header/title describing the theme is displayed

- [x] At least 10 unique events or resources are displayed

- [x] The cards are displayed in an organized responsive format (grid layout)

- [x] Each card includes:
  - [x] Title
  - [x] Description
  - [x] Date
  - [x] Image

- [x] Functional React components are used

- [x] Props are used to pass data into reusable components


### ⭐ Stretch Features

- [x] Buttons/links to related resources are included on each card component  
- [x] The site is responsive for both desktop and mobile formats
